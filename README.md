# dashboard-analitik
Dasbor analitik modern dan responsive berbasis web yang dibangun menggunakan Next.js (App Router), Tailwind CSS, dan Shadcn UI. Dilengkapi dengan fitur interaktif seperti multi-sumber data (E-commerce DummyJSON &amp; Open-Meteo Weather API), otentikasi Supabase, filter data dinamis, serta kemampuan ekspor laporan ke format PNG (grafik) dan CSV (tabel).
